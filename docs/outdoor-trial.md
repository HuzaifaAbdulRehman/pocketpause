# Outdoor trial: pending

No outdoor usage or benefit has been measured. This trial is optional
submission evidence, not a prerequisite for using the software.

Choose a safe, permitted outdoor spot yourself. Generate and read one card,
skip anything unsuitable, and put the screen away. Stay stationary and stop
if conditions feel unsafe. The selected duration is approximate.

If you try it, tell us whether the instructions fit the spot, which step you
skipped, and whether you actually put the screen away. No photograph,
recording, timed exercise or written log is required. Add only what really
happened to the DEV post. Do not claim a health effect from one trial.
