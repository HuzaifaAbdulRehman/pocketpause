# Demo

The [local video](evidence/real-demo.webm) records the actual built app:
generation with the real local model, display, then Save activity.
It is an automated desktop capture, not an outdoor trial. The corresponding
[screenshot](evidence/real-flow.png) and [download](evidence/real-card.txt)
are preserved. The video has no narration and has not been uploaded.
The final capture holds the generated card and saved confirmation for at
least four seconds each. A real-model regression checks those intervals and
that the saved confirmation is inside the recorded viewport.

If making a narrated version, show:

1. The two selectors and the absence of recordings or location requests.
2. Generate and its loading state. Keep the wait visible or label any edit.
3. The generated steps and safety reminder.
4. Save and the plain-text file.
5. The instruction to put the screen away.

Host the existing video only after publication approval, then add its
accessible URL to the DEV draft. A local file path is not a public demo link.
Do not stage runtime profiles, model weights or credentials.
